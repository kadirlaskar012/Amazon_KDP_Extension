# Extension Demo Video Assets

This folder contains the promotional and review demo video assets for **KDP Niche Finder v1.0.0**:

## Included Files
1. **`kdp_niche_finder_demo.webp`**:
   - Recorded live browser animation demonstrating:
     - Navigation to Amazon Books search
     - Score Gauge calculation (86/100, Good Opportunity)
     - 5-factor breakdown bars
     - Switching to the **Books** analysis tab
     - Weak Competitor detection with green `★ Opportunity` badges
     - Real-time title search filtering
2. **`index.html`**:
   - An interactive video player and presentation page. Double-click to open in any web browser.
3. **`demo_preview.html`**:
   - The interactive mockup page used for recording and interactive demos.

## Publishing to Chrome Web Store or YouTube
- **YouTube Link for Chrome Web Store**: The Chrome Web Store allows you to add a YouTube video URL to your listing. If you want to put this video on YouTube:
  - Upload `kdp_niche_finder_demo.webp` or record a quick screencast of `demo_preview.html` using OBS/ShareX/Windows Game Bar (Win+Alt+R) at 1080p.
  - Paste the YouTube link into the Chrome Developer Dashboard under *Store Listing -> YouTube video*.
